## 🏗️ Featured Projects

### 🔴 [WAL Engine — InnoDB-style Write-Ahead Log in Java](https://github.com/fAyr08/wal-engine)
> A from-scratch implementation of MySQL InnoDB's redo log mechanism

- LSN-based log sequencing, in-memory `LogBuffer` with configurable flush policies
- `WALWriter` with crash-recovery semantics and `MySQLApplier` for redo application
- Models InnoDB concepts: ARIES recovery, checkpoint management, group commit
- **Stack:** Java, Spring Boot, MySQL internals

---

### 🧠 [Codebase Memory Layer](https://github.com/fAyr08/codebase-memory-layer)
> AST-aware semantic search over large codebases via MCP/Cursor integration

- Parses source trees with **tree-sitter**, chunks semantically, embeds into **Qdrant**
- Exposes retrieval via MCP protocol — plug into Cursor or any LLM toolchain
- Enables context-aware code Q&A without full-repo prompting
- **Stack:** Python, tree-sitter, Qdrant, FastAPI, MCP
